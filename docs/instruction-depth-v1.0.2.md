# Enrichissement des instructions — v1.0.2

Les instructions existantes ont été conservées et enrichies par des sections opérationnelles complémentaires.
Les ajouts détaillent notamment les règles d'architecture, l'usage Java 21, les contrats Spring Boot,
les migrations Flyway, la stratégie de test, les scénarios Cucumber, les preuves de performance,
l'instrumentation Micrometer, les contrôles de sécurité, les opérations ECS et les garanties SNS/SQS.

Les instructions restent séparées par responsabilité afin de limiter le contexte injecté dans chaque tâche.
Elles ne remplacent pas la constitution ni les quality gates exécutables.
