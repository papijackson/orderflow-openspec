# SonarQube Integration

SonarQube is a quality signal and CI gate, not a replacement for architecture, tests, or security review.

Recommended gate categories:
- bugs;
- vulnerabilities;
- security hotspots;
- code smells;
- duplication;
- coverage;
- maintainability.

Configure the actual thresholds according to organizational policy.

AI-generated code receives the same SonarQube treatment as human-written code.
